# Held-out objectives

These prompts were written on 2026-11-16 and were never used to tune SlimToken's
planner or writer rules (all tuning so far used `../taskflow.txt` and `../ledgerly.txt`).
Use them to check that speed, build reliability and quality hold on apps the
engine was not shaped around. Do not derive engine rules from audits of these
apps; if a held-out audit finds a problem, fix it with a general mechanism and
re-check on a different held-out objective.
